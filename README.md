# 🍗 Frango WS

Site institucional desenvolvido para divulgação e recebimento de pedidos da Frango WS.

## 📋 Sobre o Projeto

A Frango WS é especializada em frangos assados preparados sob encomenda, oferecendo qualidade, sabor e atendimento personalizado.

O objetivo deste site é facilitar o contato dos clientes e direcionar os pedidos diretamente para o WhatsApp Business.

## ✨ Funcionalidades

* Página inicial moderna e responsiva
* Botão direto para WhatsApp
* Cardápio simplificado
* Seção Sobre
* Contato rápido
* Integração com Instagram
* Área de avaliação do atendimento

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* Responsividade Mobile
